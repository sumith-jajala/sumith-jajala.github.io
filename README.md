# Sumith Jajala — Portfolio

Professional personal portfolio built with HTML, CSS and JavaScript and designed for GitHub Pages.

## Structure

```text
.
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       └── main.js
├── .gitignore
└── README.md
```

## Before publishing

Update the GitHub, LinkedIn, email, resume and project links in `index.html`.

## Local preview

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

Push to GitHub, then open **Settings → Pages** and select **Deploy from a branch → main → /(root)**.
